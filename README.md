# 나의 레슨일지 (My Lesson Diary)

현재 안정화 버전: **2.5.0**


## v2.5.0 변경사항

- 데이터 덮어쓰기 전에 IndexedDB 안전 복구본을 자동 생성하고 최근 10개를 보관합니다. 설정 > 데이터 안전에서 수동 생성과 최근 복구본 복원이 가능합니다.
- 학생/수업/폴더의 핵심 localStorage 저장 실패(용량 부족 등)를 감지하고, 실패 시 안전 복구본을 추가로 남기도록 했습니다.
- 브라우저 저장소의 persistent storage를 요청하고 사용량/할당량을 확인할 수 있게 했습니다.
- 로컬 JSON이 손상되어 파싱되지 않을 경우 최근 안전 복구본을 자동으로 찾아 복원합니다.
- Google Drive 동기화 데이터에 `revision`, `deviceId`, `updatedAt` 메타데이터를 추가했습니다. 다른 기기에서 더 최신 데이터가 발견되면 자동 업로드를 중단하고 충돌 선택 UI를 표시합니다.
- 충돌 상태에서 현재 기기 데이터로 강제 덮어쓰기 전에 기존 클라우드 데이터를 안전 복구본으로 보관합니다.
- Google Drive에 새 파일을 만들 때 빈 데이터가 아니라 현재 기기 데이터를 업로드하도록 수정했습니다.
- Service Worker는 설치 즉시 강제 활성화하지 않고 기존 탭이 종료된 뒤 새 캐시가 활성화되도록 변경해, 실행 중인 앱과 새 캐시가 섞일 위험을 줄였습니다. 캐시는 `mylesson-v250`입니다.
- 주간 PDF의 비표준 숫자 폰트 굵기(650/750)를 600/700으로 정리했습니다.
- 개인정보처리방침에서 로컬 IndexedDB 저장과 Google 로그인 필요 기능을 실제 동작에 맞게 명확히 했습니다.

## v2.2.17 변경사항

- Google access token이 만료되어도 앱 시작/복귀 과정에서 OAuth 팝업을 자동으로 열지 않도록 변경했습니다.
- 만료 시에는 연결 상태만 `재로그인 필요`로 전환하고, 사용자가 `재로그인` 또는 Google 연결 버튼을 눌렀을 때만 인증 창을 엽니다.
- 같은 Google 계정과 같은 권한으로 재로그인할 때는 저장된 이메일 힌트를 사용해 불필요한 계정 선택 단계를 줄였습니다.
- Google Identity Services의 `popup_failed_to_open` / `popup_closed` 오류를 구분해 상태 메시지로 안내합니다.
- Service Worker 캐시를 `mylesson-v2217`으로 갱신했습니다.

## v2.2.16 변경사항

- 캘린더 학생 검색에서 오늘 이후의 예정 수업일자는 검색 결과에서 제외했습니다.
- 검색 결과는 오늘을 포함한 과거 수업일자만 표시하며, 최신 날짜가 위쪽에 오도록 내림차순으로 정렬합니다.
- 기존 수업료 납부 아이콘과 날짜 이동 기능은 그대로 유지합니다.
- Service Worker 캐시를 `mylesson-v2216`으로 갱신했습니다.

## v2.2.15 변경사항

- 주간 PDF 인쇄를 A4 가로 7열 캘린더형으로 변경했습니다.
- 일요일부터 토요일까지 날짜를 가로로 배치하고 각 날짜 아래에 수업시간과 학생 이름을 시간순으로 표시합니다.
- 한 주의 수업이 길어지면 동일한 7일 헤더를 반복한 다음 PDF 페이지로 자동 이어집니다.
- iPhone/iPad의 PDF 공유 및 프린트 흐름은 그대로 유지합니다.
- Service Worker 캐시를 `mylesson-v2215`로 갱신했습니다.

## v2.2.14 변경사항

- iPhone/iPad 캘린더 인쇄를 HTML 공유에서 실제 `application/pdf` 파일 공유 방식으로 변경했습니다.
- 월간 캘린더는 A4 가로 1페이지 PDF로 생성하며, 학생 이름은 수업시간 순으로 최대 10명까지 배치합니다.
- 주간 캘린더는 A4 세로 PDF로 생성하며, 날짜별 `시간 + 학생 이름` 목록이 길면 자동으로 여러 페이지로 나뉩니다.
- iOS에서는 생성된 PDF 파일을 Web Share API로 공유해 공유 시트의 `프린트` 항목을 사용할 수 있도록 했습니다.
- 데스크탑/기타 환경에서는 생성된 PDF를 새 탭에서 열고 PDF 뷰어의 인쇄 기능을 사용하도록 했습니다.
- 외부 PDF 라이브러리 없이 브라우저 Canvas로 인쇄 레이아웃을 렌더링한 뒤 자체 PDF 컨테이너로 묶어 오프라인에서도 동작하도록 했습니다.
- Service Worker 캐시를 `mylesson-v2214`로 갱신했습니다.

## v2.2.13 변경사항

- 캘린더에 현재 보기(월간/주간)를 인쇄하는 `인쇄` 버튼을 추가했습니다.
- 월간 인쇄는 A4 가로 전용 레이아웃을 사용하며, 날짜별 학생을 수업시간 순으로 정렬해 최대 10명까지 2열로 배치합니다.
- 주간 인쇄는 A4 세로 목록형 레이아웃으로 날짜별 수업시간과 학생 이름을 출력하며, 목록이 길면 다음 페이지로 자연스럽게 이어집니다.
- iPhone/iPad에서는 Web Share API를 우선 사용해 iOS 공유 메뉴에서 `프린트`로 접근하도록 했고, 공유를 사용할 수 없으면 일반 인쇄 화면으로 대체합니다.
- 데스크탑과 기타 환경에서는 별도 인쇄 문서를 열어 브라우저 인쇄 대화상자를 호출합니다.
- Service Worker 캐시를 `mylesson-v2213`으로 갱신했습니다.

## v2.2.12 변경사항
- 설정 화면의 Google 계정/이메일, 동기화 상태, Calendar 설정, 경고 영역이 다크모드 색상 변수를 사용하도록 수정
- 설정 토글의 제목/보조문구/구분선과 Google 연결 버튼도 다크모드에 맞게 표시
- 수업 기록 추가/수정에서 `수업 내용`을 선택 입력으로 변경
- 수업 내용이 비어 있어도 학생만 선택되어 있으면 수업 기록 저장 가능
- 빈 수업 내용은 기록 카드에서 불필요한 빈 섹션을 표시하지 않음
- Service Worker 캐시를 mylesson-v2212으로 갱신

## 개발
```bash
python3 tools/audit.py
python3 tools/build.py
```

배포 결과는 `deploy/`에 생성된다. GitHub Pages 루트에는 `deploy`의 파일들을 배치한다.

자세한 구조와 수정 규칙은 `docs/HANDOFF.md`를 참고한다.
