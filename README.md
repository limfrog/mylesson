# 나의 레슨일지 (My Lesson Diary)

현재 안정화 버전: **2.2.10**

## v2.2.10 변경사항
- 연도 선택을 숫자 입력 대신 위아래로 스크롤하는 드럼롤 UI로 변경
- 캘린더 검색창을 기본 화면에서 숨기고 `월간`·`주간` 옆 `검색` 버튼을 눌렀을 때만 표시
- 학생 검색 결과를 실제 수업 기록뿐 아니라 등록된 정기/단건 수업 일정까지 합쳐 수업일자 목록으로 표시
- 종료일이 없는 반복 수업은 과거 일정 전체와 앞으로 1년의 예정 수업일자를 표시
- 수업료 납부 기록이 있는 날짜에는 날짜 옆에 💰 아이콘 표시
- 검색 결과가 많으면 결과 영역 내부에서 스크롤
- Service Worker 캐시를 mylesson-v2210으로 갱신

## 개발
```bash
python3 tools/audit.py
python3 tools/build.py
```

배포 결과는 `deploy/`에 생성된다. GitHub Pages 루트에는 `deploy`의 파일들을 배치한다.

자세한 구조와 수정 규칙은 `docs/HANDOFF.md`를 참고한다.
