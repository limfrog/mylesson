# 나의 레슨일지 (My Lesson Diary)

현재 안정화 버전: **2.2.9**

## v2.2.9 변경사항
- 캘린더 상단의 연도·월 제목을 눌러 원하는 연도와 월로 바로 이동할 수 있는 선택 UI 추가
- 주간 보기에서 `이전 주` / `다음 주` 버튼으로 1주 단위 이동 가능
- 주간 보기의 상단 좌우 화살표도 월 이동이 아니라 앞뒤 주 이동으로 동작하도록 개선
- 캘린더에 학생 이름 검색창 추가
- 검색 결과에는 해당 학생의 실제 수업 기록 날짜를 최신순으로 표시하고, 결과가 많으면 내부 스크롤 처리
- 검색 결과의 날짜를 누르면 해당 월·날짜로 즉시 이동
- Service Worker 캐시를 mylesson-v229로 갱신

## 개발
```bash
python3 tools/audit.py
python3 tools/build.py
```

배포 결과는 `deploy/`에 생성된다. GitHub Pages 루트에는 `deploy`의 파일들을 배치한다.

자세한 구조와 수정 규칙은 `docs/HANDOFF.md`를 참고한다.
