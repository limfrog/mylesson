# Changelog

## 2.2.13 — 2026-09-27
- 캘린더의 현재 보기 상태에 따라 월간 또는 주간 일정을 인쇄할 수 있는 `인쇄` 버튼을 추가했습니다.
- 월간 인쇄는 A4 가로 전용 레이아웃으로 구성하고, 하루 학생 목록을 수업시간 순으로 정렬해 최대 10명까지 2열로 표시합니다.
- 주간 인쇄는 A4 세로 목록형으로 날짜별 수업시간과 학생 이름을 표시하며, 내용이 길면 여러 페이지로 이어집니다.
- iPhone/iPad에서는 인쇄 문서를 파일로 만들어 iOS 공유 시트를 우선 열고 `프린트` 항목으로 접근할 수 있도록 했습니다.
- 데스크탑 및 기타 환경에서는 별도 인쇄 문서를 열어 브라우저 인쇄 대화상자를 호출합니다.

## 2.2.12 — 2026-09-27
- 설정 화면의 Google 계정/이메일, 동기화 상태, Google Calendar 설정, 충돌 안내와 토글 텍스트가 다크모드에서도 올바른 배경/글자색을 사용하도록 수정했습니다.
- Google 연결 버튼과 보조 안내 문구도 테마 색상 변수를 사용하도록 정리했습니다.
- 수업 기록 추가/수정에서 `수업 내용` 필드를 필수 입력에서 제외했습니다.
- 수업 내용이 비어 있어도 저장할 수 있으며, 빈 수업 내용 섹션은 기록 카드에서 숨깁니다.

## 2.2.11 — 2026-09-27
- 캘린더 위에 전체 학생 이름과 전공을 항상 나열하던 범례 영역을 제거했습니다.
- 학생 이름은 검색 결과, 선택 날짜의 상세 목록, 주간 일정 등 필요한 맥락에서만 표시되도록 정리했습니다.

## 2.2.10 — 2026-09-27
- 캘린더 연도 선택을 숫자 입력에서 스크롤 스냅 방식의 드럼롤 UI로 변경했습니다.
- 캘린더 검색창은 기본적으로 숨기고 `월간`·`주간` 옆의 `검색` 버튼을 눌렀을 때만 표시하도록 변경했습니다.
- 학생 검색 결과를 실제 수업 기록 날짜뿐 아니라 등록된 정기/단건 수업 일정에서 계산한 수업일자까지 합쳐 표시합니다.
- 종료일이 없는 반복 일정은 과거 일정 전체와 앞으로 1년의 예정 수업일자를 검색 결과에 포함합니다.
- 수업료 납부 기록이 있는 수업일자는 날짜 옆에 💰 아이콘을 표시합니다.

## 2.2.9 — 2026-09-27
- 캘린더 상단의 연도·월 제목을 버튼으로 바꾸고, 원하는 연도와 월을 직접 선택해 이동할 수 있는 UI를 추가했습니다.
- 주간 보기에서 `이전 주` / `다음 주` 버튼을 추가하고, 상단 좌우 화살표도 주간 보기에서는 1주 단위로 이동하도록 변경했습니다.
- 캘린더에 학생 이름 검색을 추가했습니다. 검색 결과에는 해당 학생의 실제 수업 기록 날짜가 최신순으로 표시됩니다.
- 검색 결과가 많으면 결과 영역 내부에서 스크롤되며, 날짜를 선택하면 해당 월과 날짜로 바로 이동합니다.

## 2.2.8 — 2026-09-27
- 앱 시작 시 저장된 Google 계정의 access token이 만료되었거나 5분 이내 만료 예정이면 재로그인 안내 전에 자동 재연결을 시도하도록 변경했습니다.
- Google Identity Services 스크립트가 늦게 로드되는 경우 최대 약 6초 기다린 뒤 토큰 갱신을 시도하도록 했습니다.
- 앱이 백그라운드에서 다시 활성화되거나 iOS PWA가 재개될 때 토큰 상태를 다시 확인하고 필요하면 자동 갱신하도록 했습니다.
- 자동 토큰 갱신 요청을 단일 in-flight 작업으로 묶어 중복 요청을 방지했습니다.
- 토큰 유효 판정과 자동 갱신 시점을 만료 5분 전으로 통일했습니다.
- 자동 갱신 실패 시에만 기존의 재로그인 안내를 표시하도록 했습니다.
